Primeiro contato com o programa

Um treinamento realmente inicial: abrir, conhecer o editor, navegar e salvar o primeiro desenho.

1. O que você baixou?

O WMK CAD Studio é um editor CAD 2D em Rust. O arquivo WMK-CAD-Studio.exe é a aplicação Windows Portable; não precisa de instalador. Descompacte o ZIP para uma pasta com permissão de escrita, por exemplo D:\Ferramentas\WMK-CAD-Studio. Não execute o EXE de dentro do ZIP.

Abra manuais/index.html no navegador para estudar offline. Evite colocar somente o EXE fora da pasta enquanto estiver aprendendo, pois a distribuição também contém exemplos e documentação.

2. Entendendo a janela

RegiãoComo funciona
Área centralCanvas CAD. A grade indica localização no desenho; as coordenadas são unidades do desenho, não pixels.
Barras e conjuntos de ferramentasComandos de desenho, modificação, anotação, seleção e visualização.
Painel Camadas / LayersLiga/desliga, bloqueia e define cores de grupos de entidades.
Painel PropriedadesExibe geometria e atributos do objeto selecionado.
Linha de comandoDigite comandos como LINE, CIRCLE, OFFSET e ZOOM. O programa apresenta instruções do próximo passo.
Abas de desenho/layoutAlternam entre desenho no espaço do modelo e pranchas de apresentação.

3. Abrir um desenho pronto

  1. Clique em Abrir no menu principal (ou na tela inicial).
  2. Entre na pasta exemplos da edição Portable e selecione apartment.dxf.
  3. Use ZOOM → Extents ou digite ZOOM e escolha E para enquadrar o desenho.
  4. Role o scroll para aproximar/afastar; pressione e arraste o botão do meio para deslocar a visão.
  5. Clique em uma entidade e observe suas propriedades. Explore a lista de camadas.
  6. Salve uma cópia usando Salvar como, sem sobrescrever o original.
Se a tela parecer vazia: não significa que o arquivo está vazio. Faça Zoom Extents. Confira se as camadas relevantes estão visíveis e se o espaço correto (Model/Layout) está ativo.

4. Primeira linha — usando o prompt

LINE
0,0
4000,0
ENTER

O comando acima cria um segmento de 4.000 unidades entre dois pontos, se o desenho estiver configurado para usar milímetros. Você pode digitar LINE 0,0 @4000,0 se o parser de comandos da versão aceitar os argumentos numa só linha; caso contrário, siga as perguntas exibidas na linha de comando. Finalize o comando com Enter ou Esc conforme o estado.

5. O que são coordenadas?

(x,y) é a posição no plano. Exemplo em milímetros: (0,0) é a origem e (4000,3000) está a 4 m para a direita e 3 m para cima. O programa não presume que cada unidade representa um milímetro: confira Drawing Units / Unidades de desenho.

6. Desfazer, selecionar e salvar

Faça mudanças em uma cópia do desenho; use Ctrl + Z para desfazer quando o atalho estiver habilitado. Em desenhos complexos, confira a linha de comando e a seleção ativa. Use Salvar como para escolher DXF/DWG e depois abra o arquivo salvo para verificar fidelidade.

7. O que não esperar desta versão

Ela não cria automaticamente uma casa 3D e não dispõe ainda de importação nativa completa de JPG/PNG/PDF como imagem de fundo. Exportar uma planta para PNG/PDF já é outra função, que existe. A importação inteligente está em desenvolvimento na suíte WMK.

Exercício proposto

  1. Abra apartment.dxf.
  2. Identifique uma linha, um texto, uma cota e uma camada.
  3. Desligue e religue a visibilidade de uma camada.
  4. Salve a cópia como apartamento-teste.dxf.
  5. Feche e reabra essa cópia; confira se as entidades permaneceram.
